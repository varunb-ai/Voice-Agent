# everything it needs. requirements.txt additionally carries the legacy
# local-audio pipeline and the pre-Twilio scaffolding — crawl4ai, playwright,
# langgraph, celery, prometheus-client, psycopg, faster-whisper, webrtcvad —
# none of which any live module imports.
#
# VERIFIED, NOT ASSERTED. The offline suite was re-run with faster_whisper,
# langgraph, piper, prometheus_client, psycopg, redis and webrtcvad made
# unimportable by a meta_path blocker, and passed 2164/0. A green run with
# everything installed proves nothing about a subset; blocking the difference
# does. CI now re-proves it on every push, because it installs from THIS FILE
# and runs the suite against it.
#
#   pip install -r requirements-realtime.txt
#
